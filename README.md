# Ronixe Landing Page (Vanilla Version)

This is a clean, minimalist landing page built with pure HTML, CSS, and Vanilla JavaScript.

## 📁 Project Structure
- `index.html`: The main structure (8 sections).
- `style.css`: All styling, including animations and glassmorphism.
- `main.js`: Scroll animations and navbar logic.
- `assets/`: Logos and icons.

## 🚀 Getting Started
There is no build step. Simply open `index.html` in your favorite web browser.

## 🛠 Features
- **Zero Dependencies**: Fast load times and easy maintenance.
- **Intersection Observer**: Modern scroll-to-reveal animations.
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop.
- **Glassmorphism UI**: High-fidelity design using standard CSS filters.

## 📦 Deployment
Since this is a static project, you can deploy it anywhere:
1. **GitHub Pages**: Push this repo and enable Pages in settings.
2. **Netlify/Vercel**: Drag and drop the folder into their dashboard.
3. **Traditional Hosting**: Upload the files via FTP.
